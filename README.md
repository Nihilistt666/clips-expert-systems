# Експертні системи на базі CLIPS

Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Автор
- Студент: Рязанець В.Д
- Група: ІН-33

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts);
- `Lab2/` – створення шаблонів (deftemplate) та впорядковані факти;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – префіксні вирази та додавання двійкових чисел на правилах;
- `README.md` – опис проєкту.

## Висновки
У ході роботи до репозиторію перенесено програми CLIPS з лабораторних робіт 1–5: десять файлів у `Lab1`, по два файли в `Lab2`, `Lab3` і `Lab5` та один файл у `Lab4`. Кожна папка містить також власний `README.md` з описом роботи й переліком файлів.

Під час перенесення проєкту до GitHub труднощі виникли зі створенням папок, оскільки Git не зберігає порожні папки. Тому кожну папку `LabN` спочатку створено як файл `LabN/README.md` через Create new file, а файли `.clp` завантажено вже в готову папку через Upload files. Коментарі українською мовою у файлах `.clp` відображаються на GitHub правильно, бо файли збережено в кодуванні UTF-8.
