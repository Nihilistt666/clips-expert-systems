# Експертні системи на базі CLIPS

Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Автор

- Група: ІН-33

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts);
- `Lab2/` – створення шаблонів (deftemplate) та впорядковані факти;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – дерева рішень та логічне виведення;
- `README.md` – опис проєкту.

Кожна папка має свій `README.md` з коротким описом роботи та переліком файлів. Усі `.clp` файли завантажуються в оболонку CLIPS командою `(load "файл.clp")`, після чого виконуються `(reset)` і `(run)`.

## Висновки
Під час роботи вдалося зібрати в одному місці всі програми CLIPS з перших п'яти лабораторних: факти, шаблони, правила й функції. Тепер код не загубиться разом з комп'ютером, а будь-яку попередню версію можна знайти в історії комітів.

Робота з GitHub показала, що для кожної зміни варто робити окремий коміт зі зрозумілим описом. Тоді історія проєкту читається як журнал виконаних робіт.

Головна незручність виникла з папками: Git не зберігає порожні папки, тому кожну папку `LabN` спочатку створено через файл `LabN/README.md`, а вже потім у неї завантажено код. Ще одна дрібниця – кирилиця в коментарях `.clp` файлів. На GitHub вона відображається правильно, бо файли збережено в UTF-8.
